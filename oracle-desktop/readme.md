# 🔮 Scrylytics Oracle Desktop Prototype

Transparent Electron + React + Three.js overlay for Hearthstone.  
Watches `Power.log` in real time and glows when new events occur.  
Includes mock-event mode if no logs are found.

---

## 🧰 Prerequisites

- **macOS or Windows**
- **Node.js 20+**
- **npm 9+**
