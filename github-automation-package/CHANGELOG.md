# Changelog

All notable changes to the GitHub Project Automation package will be documented in this file.

## [1.0.0] - 2024-01-XX

### Added
- Initial release of GitHub Project Automation package
- Project Auto workflow - automatically adds issues/PRs to project boards
- Project Status workflow - updates project status based on PR lifecycle
- Project Field Mapper workflow - maps GitHub labels to project fields
- Status Comment Bot workflow - posts status updates on linked issues
- Auto Label workflow - labels PRs based on file paths
- Skip Vercel Deployment workflow - intelligently skips deployments
- Branch protection setup script
- Secrets setup helper script
- Installation script
- Issue and PR templates
- Comprehensive README documentation
- Quick start guide
- Configuration example file

### Features
- Automatic project board management
- Smart status tracking
- Label-based field mapping
- Path-based auto-labeling
- Deployment skip detection
- Branch protection automation
- Issue/PR templates
